# Повторна серія: 30 натурних запусків

Два повтори п'яти сценаріїв у трьох режимах, seed 29. Початкова source
ревізія генератора 6bb1f2c, дерево чисте. Фактичні Docker image IDs записані
в metadata primary.json: програма відповідає fc0d7bd; зміни Linux BOOTTIME
перевірялися окремо й не входили в образ цієї серії. Образи не змінювались
між режимами. Порядок режимів і сценаріїв перемішаний детерміновано.

Усі 30 станів і 30 діагностичних результатів відповідають внесеним faults.
24 одиничні несправності дали підтриманий клас, 6 HTTP+DNS — inconclusive.
Помилок harness немає. Healthy відновлювався між епізодами; ground truth
не передавався планувальнику. Raw JSON/CSV/log збережено без редагування.
[RESULTS.md](RESULTS.md) автоматично згенеровано з цих даних.

Adaptive і Fixed виконали по 4 completed probes, Static — по 6. Отримане
скорочення щодо Static не доводить переваги Adaptive над Fixed. Різницю часу
на спільному Docker-хості не слід трактувати як статистично значущу.
Два повтори — обмежена серія, не гарантія точності на інших несправностях.
Множинні/невідомі faults з еквівалентним pattern залишаються обмеженням.
Мережеві байти не вимірювалися.

Відтворення: lab_experiment.py --policy confirmed --repetitions 2 --seed 29
з новим output. Скрипт відмовляється перезаписувати попередні результати.
